# 占位符使用说明

在 HTML 或邮件正文里写入下方标记后，平台会在部署或发信时自动替换成真实内容。

两套占位符互不通用：

- **项目落地页**里的标记，不要写进邮件
- **邮件**里的标记，不要写进项目 HTML

页面库 / 页面构建预览**不会**替换项目占位符；请把 HTML 上传到「项目管理」并构建/启动后再生效。

---

## 一、项目落地页（项目管理）

上传到项目的钓鱼页 HTML 可使用以下占位符。

| 占位符 | 用途 | 填写建议 |
|--------|------|----------|
| `{{SUBMIT_URL}}` | 表单提交地址 | **建议必写**，用作表单 `action` 或接口地址 |
| `{{REDIRECT_URL}}` | 提交后跳转的原始网站链接 | 按需，对应项目里的「原始链接」 |
| `{{QR_RELAY_URL}}` | 实时二维码图片地址 | 需要扫码展示时使用；须在项目中绑定 QR 中继 |
| `{{QR_RELAY_IMG}}` | 整段二维码 `<img>` 标签 | 同上；写这一项即可，不必再手写 `img` |

### 示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8" />
  <title>登录</title>
</head>
<body>
  <h1>请登录</h1>

  <form method="POST" action="{{SUBMIT_URL}}">
    <input name="username" placeholder="账号" required />
    <input name="password" type="password" placeholder="密码" required />
    <button type="submit">登录</button>
  </form>

  <!-- 扫码登录：先在「QR 钓鱼」创建中继，再在项目中绑定 -->
  <h2>扫码登录</h2>
  {{QR_RELAY_IMG}}

  <!-- 也可以自己写图片标签：
  <img src="{{QR_RELAY_URL}}" alt="扫码登录" width="240" height="240" />
  -->

  <p><a href="{{REDIRECT_URL}}">返回官网</a></p>
</body>
</html>
```

### 使用步骤（含二维码时）

1. 工作台 → **QR 钓鱼**：创建中继，按说明运行本地脚本上传画面  
2. **项目管理**：新建或编辑项目，上传含占位符的 HTML，在「QR 中继」中选择该中继  
3. 构建并启动项目  
4. 用项目访问地址打开页面，确认提交地址与二维码已显示  

### 注意

- 修改「原始链接」、更换绑定的中继，或轮换了公开链接后，请**重新构建或重新启动**项目后再查看效果。  
- 未绑定中继，或中继已暂停时，`{{QR_RELAY_URL}}` / `{{QR_RELAY_IMG}}` 会变成空白。  
- `{{QR_RELAY_IMG}}` 本身就是一整段标签，请单独成行，不要写成 `src="{{QR_RELAY_IMG}}"`。

## 二、邮件正文（工作台 → 发送邮件）

编写邮件时可使用以下占位符。发信时会对每个收件人分别替换。

| 占位符 | 用途 | 填写建议 |
|--------|------|----------|
| `{{email}}` | 当前收件人邮箱 | 需要称呼时写入 |
| `{{click_url}}` | 可追踪的跳转链接 | **建议必写**，用作按钮或超链接的 `href` |
| `{{landing_url}}` | 落地页地址 | 一般可不用；优先使用 `{{click_url}}` |
| `{{open_pixel}}` | 打开统计用的隐藏图片地址 | 可选；开启「追踪打开」时，不写也会自动处理 |

### HTML 示例

```html
<p>您好，{{email}}：</p>
<p>请点击下方链接完成验证：</p>
<p><a href="{{click_url}}">立即验证</a></p>
```

### 纯文本示例

```text
您好，{{email}}：
请打开以下链接完成验证：
{{click_url}}
```

### 注意

- 请把 `{{click_url}}` 放在用户能点击的链接上，不要只写落地站明文地址。  
- 「追踪打开」仅对 **HTML** 邮件有效。  
- 邮件占位符与项目落地页占位符不能混用。
